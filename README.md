# Celebal Learning Engagement Program – Data Engineering Internship

## About the Repository

This repository contains the tasks, assignments, practical exercises, and learning activities completed as part of the **Celebal Learning Engagement (CLE) Program – Data Engineering Internship**.

The repository documents my learning journey and hands-on experience with data engineering concepts, tools, and technologies throughout the program.

## Learning & Technologies

The program covers practical learning and implementation using the following technologies:

- **SQL:** Database creation, data retrieval, filtering, joins, aggregations, CTEs, and window functions.
- **Python:** Programming fundamentals and data manipulation.
- **Apache Spark:** Distributed data processing and Spark fundamentals.
- **PySpark:** Data transformation, cleaning, and ETL operations.
- **Azure:** Cloud fundamentals and data engineering services.
- **Azure Data Factory:** Data integration and pipeline orchestration.
- **Azure Databricks:** Data processing and analytics.
- **Delta Lake:** Reliable data storage and data management.
